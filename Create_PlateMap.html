CFX Maestro 96-Well Plate Map Generator

Designed for Bio-Rad CFX Maestro 2.2, version 5.2.008/0222 (2021)

1. Sample List

Paste one sample/isolate per line.

Blank lines are ignored.
Sample names are preserved exactly as pasted, including capitalization, spaces, punctuation, and numbers.

2. Controls

Important: Controls are used here to identify and visually highlight control wells in the plate map. Because the CFX Maestro CSV template supplied for this application contains only:

Row, Column, *Target Name, *Sample Name, *Biological Group

the control type is not exported to the CSV. After importing the plate map into CFX Maestro, assign the appropriate Sample Type (NTC, Positive Control, Negative Control, etc.) in the software.
Enter one or more sample names exactly as they appear in the sample list.
Multiple names can be separated by commas.

Example: Water, Blank, NTC1
Example: 794
Leave blank if you do not have a negative control.
Case-sensitive: Control names must match the pasted sample name exactly. For example: Water matches Water, but water does not.

3. Technical Replicates

Default: duplicates.
Vertical: replicates are stacked down the same column.
Horizontal: replicates are placed across adjacent columns.
Important — Replicate assignment: This tool places the replicate wells together in the requested orientation, but it does not assign a Replicate # in the CSV. After importing the plate map into CFX Maestro, you will need to assign the technical replicate groups using the CFX Maestro software.

4. Target

Enter the target name used for this assay.
Example: Folac
Using two targets? This generator creates the plate map for one target. If your experiment has a second target, it is easier to add/configure that target directly in CFX Maestro after the plate map has been uploaded.

5. Biological Group

Biological Group is intentionally left blank.

You can add or edit Biological Group information easily in CFX Maestro after the plate map has been uploaded.

CFX Maestro CSV Data

The exported CSV contains exactly these five columns:

Row | Column | *Target Name | *Sample Name | *Biological Group

Biological Group is left blank. Replicate numbers and Sample Type are not exported.

Export

Your plate map has been generated.

Review the plate carefully before importing it into CFX Maestro. After importing:
  • Assign NTC / Positive Control / Negative Control Sample Types in CFX Maestro.
  • Assign technical replicate groups in CFX Maestro.
  • Add Biological Group information if needed.
  • Add a second target if required.
Target software: Bio-Rad CFX Maestro 2.2, version 5.2.008/0222 (2021).

CSV structure: This application uses the five-column CFX Maestro template supplied by the user:
Row | Column | *Target Name | *Sample Name | *Biological Group

The application runs entirely in your browser. Sample information is not uploaded to a server.

Always inspect the generated plate map and verify the imported plate in CFX Maestro before beginning an experimental run.
